# Virtual Pit Wall design system

The interface uses a flat, dark operations-room language: graphite canvas, charcoal working surfaces, fine structural rules, and compact data typography. Red marks active navigation, green marks healthy/live states, and amber is reserved for delay, uncertainty, or experimental strategy.

- Display: Barlow Condensed
- Interface: IBM Plex Sans
- Telemetry and time: IBM Plex Mono
- Base canvas: `#080c0f`
- Rules: `#28333a`
- Text: `#f2f4f5`
- Accent: `#ef3340`
- Semantic live: `#46d47b`
- Semantic caution: `#ffb82e`

Spacing follows open horizontal bands and dense tables rather than a floating-card grid. Corners stay square or use a restrained 3–4 px radius. All controls expose visible keyboard focus, status meaning is repeated in text, and animation respects reduced-motion preferences.
