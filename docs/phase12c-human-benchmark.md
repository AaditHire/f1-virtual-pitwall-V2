## Annotation workflow and schemas

`scripts/annotate_phase12c.py` is a local-only, blind browser workflow with audio playback/replay, neutral IDs, draft/complete saves, resume support, `[inaudible]` insertion, usability and speaker labels, human-derived critical terms, and annotation notes. The browser API excludes race/driver/lap context and all prediction text or diagnostics. Audio is fetched on demand from the frozen Phase 12A sanitized reference and held only for the response.

Human references are stored separately in `docs/phase12c-radio-human-references.json` under schema version `1.0`:

- `clip_id`
- literal `reference_transcript`
- `usability`: `CLEAR | PARTIAL | POOR | UNUSABLE`
- `speaker_type`: `DRIVER | ENGINEER | MIXED | UNKNOWN`
- human-derived `critical_terms` with controlled categories
- optional `notes`
- `complete`, fixed `annotation_source: human`, and timestamp

Unknown fields are rejected. A complete record requires transcript, usability, and speaker type; every critical term must occur in the human reference. This prevents ASR fields from being serialized as human labels.

Post-reference human semantic labels are stored separately in `docs/phase12c-radio-semantic-review.json`. Each frozen model/clip pair requires `SAFE_EQUIVALENT`, `MINOR_ERROR`, or `MATERIAL_ERROR` with fixed `reviewer_source: human` before evaluation can run.

## Reproducible scoring

`scripts/phase12c_benchmark.py` implements deterministic WER, CER, exact normalized critical-term recovery, and evaluation artifact generation. Text uses Unicode NFKC normalization, case-folding, punctuation removal, and collapsed whitespace. `[inaudible]` is a zero-cost wildcard for an arbitrary hypothesis span and is excluded from the reference denominator.

`scripts/evaluate_phase12c.py` uses the unchanged Phase 12B `small.en` and `medium.en` predictions. It refuses to emit an evaluation artifact until all 30 human references and all 60 human semantic comparisons are complete.
